# Airframe Brief

OEM sentiment for Airbus, Boeing, Embraer, COMAC, ATR, and Bombardier, from public posts only.

Live site: https://anon-astra.github.io/twt-sentiment/

## What the reader will do

- Read one public post link at a time, or refresh counts on at most four posts already on screen
- Skip protected accounts, profiles, and search pages
- Stop after eight reads a minute
- Score with a visible word list, not a hidden model

## What it will not do

- Log in, crawl follower graphs, or read direct messages
- Treat the score as a poll, a safety rating, or investment advice

The checked-in sample was collected on 30 Sep 2026 from public keyword search. It is directional, not representative.

```bash
npm install
npm run dev
npm run build
```
